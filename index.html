Nightly builds are updated frequently, contain experimental features and may have significant, potentially game-breaking bugs. Only use them if you know what you're doing.

Components

MojoLauncher is assembled from open-source components, most of them maintained under the MojoLauncher organisation.

LTW - Large Thin Wrapper

A thin OpenGL-to-OpenGL ES 3 translator that partially implements OpenGL 3.3 Core.

LGPL-3.0 View LTW on GitHub

GL4ES

A highly efficient OpenGL-to-OpenGL ES 2 translator with fixed-function pipeline support. The Holy GL4ES fork includes extended shader capabilities and mod support.

View Holy GL4ES on GitHub MIT

MojoExec

A utility library that implements custom Vulkan and OpenGL driver loading

MIT View MojoExec on GitHub

SDL / GLFW

The two interchangeable window and input backends. Both create the game window and handle keyboard, mouse and gamepad input; the launcher picks SDL3 or GLFW depending on the game's requirements.

Both SDL3 and GLFW are maintained as forks adapted for running desktop applications in MojoLauncher.

SDL zlib GLFW zlib

OpenJDK

The Java runtime that powers the game. The MojoLauncher OpenJDK builds are compiled for all major Android architectures and include patches for reliable networking, X11-free AWT GUI and fixes for Android quirks.

OpenJDK builds GPL-2.0

Mesa 3D

A fork of the Mesa 3D project with additional compatibility patches for Turnip, Android EGL support for Kopper and Freedreno (Gallium) on KGSL.

Due to abuse by third parties, the fork is not available to the public

Upstream Mesa MIT
